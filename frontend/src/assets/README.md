# Assets Folder

This folder contains all static assets for the City Environment and Parks Management Office application.

## Folder Structure

### `/images/`
- Logos and brand images
- Background images
- Illustrations and graphics
- Photos related to parks and environment

### `/icons/`
- SVG icons
- Favicon files
- UI icons (user, lock, etc.)
- Environmental icons

### `/styles/`
- Additional CSS files
- Style utilities
- Theme variables
- Animation styles

## Usage

Import assets in your components:

```javascript
// Images
import logoImage from '../assets/images/logo.png';

// Icons
import UserIcon from '../assets/icons/user.svg';

// Styles
import '../assets/styles/custom.css';
```

## Guidelines

- Use descriptive filenames
- Optimize images for web
- Keep SVGs for icons when possible
- Maintain consistent naming conventions
- Use appropriate file formats (SVG for icons, PNG/JPG for photos)
